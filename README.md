# Host Protocol (Fabric 1.20.1)

Мод **Host Protocol** — интро: заставка, расширенные титры с Испытуемым (ID на мир), ошибка подключения и глитч-материализация персонажа. Пока интро идёт, мир заморожен и игровые звуки не проходят. После завершения выдаётся **один КПК / Host Protocol PDA** (с короткой материализацией), на экране всегда виден **счётчик дней**, на рассвете — объявление нового дня. Со 2-го дня **сразу** (не только ночью) стартует очаг заражения. Через ~20–30 с — координаты (чат + title + голос); ещё ~5–10 с — auto-Septic даже без сна. `/hostprotocol day2` прогоняет всё одной командой. Если остаётесь в мире на **день 3** ~10 с — kick на title и файл на рабочем столе. Дальше: **сканер (луч) → скан железной руды → лабораторный стол + оболочка MK-II → перенос ассистента → сыворотка/костюм**, заражённые мобы у очага, **день 5 — присутствие Septic**.

- **modid:** `hostprotocol`
- **Minecraft:** 1.20.1
- **Loader:** Fabric
- **Java:** 17+

## Требования

1. **JDK 21** для Gradle/Loom (сборка). Игра/мод компилируются под **Java 17** (`options.release = 17`).
2. Интернет при первом билде (Gradle скачает Minecraft, mappings, Fabric).
3. Fabric API 1.20.1 в папке `mods`.

Проверка Java:

```bat
java -version
```

Нужен **21.x** (или новее) в PATH для `gradlew`. Если есть только JDK 17 — поставьте Temurin 21; мод всё равно рассчитан на MC 1.20.1 / Java 17 runtime.

## Как тестировать интро (новый мир)

Интро показывается **один раз на мир**. Для полного прогона:

1. Соберите мод (`./gradlew build`) и положите jar + Fabric API 1.20.1 в `mods`.
2. Запустите Minecraft 1.20.1 (Fabric).
3. Создайте **новый мир** (не заходите в уже существующий, если интро там уже прошло).
4. Ожидаемая последовательность:
   1. Чёрный экран **HOST PROTOCOL** / «Подключение…» / «Нажмите, чтобы продолжить».
   2. Титры (строка 1 — **Испытуемый {ID}**, дальше расширенный лор).
   3. «Ошибка подключения к системе. Внедрение испытуемого…»
   4. **Материализация** (~2–4 с): scanlines, джиттер, фиолетово-чёрные вспышки (`#7b2cbf`), текст «Материализация испытуемого {ID}», голос + hum/static/glitch.
   5. Камера на мгновение в третьем лице, персонаж «собирается» с глитчем; после закрытия экрана — частицы (portal / end_rod / smoke) ~2 с и затухание оверлея.
   6. **Появление КПК** (~2.5 с): голограмма/глитч перед игроком, затем **один** стак в инвентаре. На земле у ног второй копии нет.
   7. Сверху экрана — компактный HUD «День 1» / «Day 1».
5. Повторный вход в **тот же** мир интро не показывает.

### Заморозка мира (до конца интро)

Пока интро не завершено (и во время `/hostprotocol replayintro`):

- `IntroScreen` — пауза-экран (unpublished singleplayer не тикает).
- Сервер дополнительно стопит сущности / спавн / block entities, даже если открыт LAN или dedicated.
- Игровые категории звуков (мобы, амбиент, музыка мира) глушатся; голоса интро (MASTER / UI) остаются.
- Отключение клиента посреди интро **снимает заморозку**; интро остаётся незавершённым и покажется снова при входе.

Проверка:

1. Новый мир, сразу после входа: мобы не ходят, амбиент/AI-звуки мира не слышны, персонаж не падает/не действует.
2. Дождитесь материализации (или прокликайте интро). После закрытия экрана мир снова живой.
3. `/hostprotocol replayintro` — снова тишина и стоп; после сцены — снова движение. КПК не дублируется.

### КПК (PDA) — ровно один

Предмет `hostprotocol:pda` — **«КПК Host Protocol»** / **Host Protocol PDA**.

- Выдаётся **один раз** игроку при первом успешном завершении интро (и при входе в мир, где интро уже пройдено, если КПК ещё не выдавали).
- Сначала короткий cinematic (~2.5 с): глитч/scanline/фиолетовая голограмма перед игроком + SFX, затем **один** стак в инвентаре.
- **Нет** второй копии на земле у ног. Старые item-entity `hostprotocol:pda` рядом с игроком при выдаче деспавнятся.
- Флаг `pdaGiven` / delivered пишется в данные мира: повторный вход и `/hostprotocol replayintro` **не** выдают второй стак и **не** повторяют cinematic выдачи.
- ПКМ открывает КПК. Вкладки **День 1** (брифинг), после 2-го дня **День 2** (лог заражения) и **ЧЕРТЕЖ** (сетка крафта сканера), после 3-го дня **День 3**. После взлома протокола — **СБОЙ**.

Повтор интро без нового мира (для отладки):

```
/hostprotocol replayintro
```

Команда сбрасывает флаг интро у мира, снова замораживает мир и запускает сцену. Флаги выдачи КПК, лога дня 2 и объявленного дня **не** сбрасываются.

Проверка «один КПК»:

1. Новый мир → пройти интро → дождаться появления КПК → открыть инвентарь: **один** стак, на земле пусто.
2. `/hostprotocol replayintro` → снова интро → после сцены по-прежнему **один** КПК, cinematic выдачи нет.
3. `/hostprotocol status` — `PDA stacks` должен быть `1`.

### Счётчик дней (HUD) и рассвет

День считается по **дневному времени мира** (`Level#getDayTime()`), не по `getGameTime()`:

```
dayIndex = floor(dayTime / 24000) + 1
```

День 1 — первые 24000 тиков после спавна (рассвет первого дня = 0). Когда солнце всходит в следующий цикл (`24000`, `48000`, …), индекс становится 2, 3, …

Сверху по центру всегда виден компактный HUD: «День N» / «Day N» (стиль Host Protocol, скрывается во время интро и при F1).

Когда наступает **новый** день (игрок уже в мире, интро не идёт):

- один раз показывается оверлей «Наступил N день» / «Day N has begun»;
- повторный вход **среди** того же дня оверлей не спамит;
- настоящий рассвет (или команда ниже) объявляет снова.

**Как проверить без ожидания ночи** (нужны читы / `/time`):

```
/time add 24000
```

или с чистого мира, чтобы прыгнуть на рассвет дня 2:

```
/time set 24000
```

Важно: `/time set day` ставит часы на `1000` (утро) **текущего** дня и **не** увеличивает индекс. Сон до утра в ванили переводит на рассвет следующего дня — тоже валидный тест.

После перехода на день 2:

1. HUD меняется на «День 2».
2. Оверлей «Наступил 2 день».
3. **Очаг заражения стартует сразу** (не ждет ночи): чат «Очаг заражения активен» + title.
4. Откройте КПК — вкладка **День 2** и **ЧЕРТЕЖ** (сетка крафта сканера).
5. Через **20–30 секунд gameTime** — координаты (чат X/Y/Z, title, FX, голос `coords_announce`).
6. Ещё **5–10 секунд** — auto-Septic (даже без сна).

`/time add 24000` с дня 1 достаточно. Ночь дня 2 — только запасной триггер.

## День 2: очаг заражения

Триггер (см. `ProtocolTime`):

```
dayIndex = floor(dayTime / 24000) + 1
```

Очаг активируется, как только **`dayIndex >= 2`** (рассвет дня 2 / `/time add 24000` / `/time set 24000`). Ночь дня 2 (`37000`) остаётся catch-up, если активация почему-то пропущена.

После активации:

- В мире появляется **постоянный очаг** (координаты пишутся в данные мира).
- Чанки очага удерживаются загруженными (`/forceload`-эквивалент).
- Ближайшие блоки из стартового набора медленно переписываются в заражённые варианты: камень, булыжник, земля, трава, дубовый ствол/доски.
- Визуал: исходный блок **фиолетово-заражён** — тёмный тинт + яркие вены оверлея (без mipmap, `shade:false`) и редкие частицы `witch` / `reverse_portal`. Снаружи очаг читается сразу.
- Заражённые блоки **нельзя сломать**.
- Вода / биомы / лечение — не в этом релизе.

Сервер **громко логирует** каждый шаг: `INFECTION ACTIVATED`, `COORDS UNLOCKED`, `SEPTIC LINK FIRED`, `DAY3 KICK`.

### Координаты очага

Таймер — **gameTime**, ~**20–30 секунд** реального тиканья (20 т/с). Не зависит от `/time set`. Если мир загрузили уже после дедлайна — лок **сразу**. День ≥ 3 — запасной мгновенный лок.

На открытии (нельзя пропустить):

- несколько **жирных** строк в **системный чат** с X / Y / Z (не actionbar);
- ванильные **title / subtitle**;
- полноэкранный FX;
- женский голос `coords_announce.ogg` + лёгкие помехи;
- штамп в **КПК**.

### Septic (авто + сон)

Через **5–10 с gameTime после координат** cinematic запускается **сам**, даже если игрок не спал.

Сон в день 2+ (пока handshake не сыграл) — запасной триггер (`BedBlock` + `ServerPlayer.startSleepInBed` + Fabric). Ночь **не** пропускается на эту первую попытку.

На запуске: жирный чат («кто-то пытается подключиться»), титры **«ПОДКЛЮЧЕНИЕ… / SEPTIC»**, FX, голоса `septic_link.ogg` затем `septic_drop.ogg`, чат разрыва.

### Отладка одной командой

```
/hostprotocol day2
```

1. Закрывает интро и снимает freeze, если нужно (КПК выдаётся).
2. Ставит дневное время на день 2 (`24000`), если ещё день 1.
3. Принудительно активирует очаг (чат + title).
4. Через ~1 с — координаты (чат/title/FX/голос).
5. Через ~4.5 с — Septic.

Также остаются `/hostprotocol forcecoords` и `/hostprotocol forceseptic`.

### Сканер (крафт + чертёж)

Предмет `hostprotocol:scanner` / **Сканер**. Шейп на верстаке 1.20.1:

```
Diamond | Iron Ingot | Copper Ingot
Iron Ingot | Glass Block | Copper Ingot
Diamond | Iron Ingot | Copper Ingot
→ Scanner
```

Вкладка КПК **ЧЕРТЕЖ** рисует эту сетку **иконками предметов** (как ванильный верстак) + слот результата «Сканер».

### Сканер: луч, прогресс, руда / мобы

Удерживайте **ПКМ**, глядя на цель (raycast ~8 блоков):

- Фиолетовый луч Host Protocol (линии + частицы `end_rod` / `witch`) от сканера к точке попадания.
- Полоса прогресса на экране (проценты).
- **Руда** (уголь / железо / медь / золото / редстоун / лазурит / алмаз / изумруд / кварц / ancient debris, включая deepslate/nether): ~2.5 с, **один раз на BlockPos**. Повтор — короткий fail buzz и «уже просканировано».
- **Живые сущности**: ~1.5 с, можно сканировать много раз; каждый успех — чат-пинг и строка в сенсорном логе КПК.
- Отпустите ПКМ, отведите взгляд или отойдите дальше ~3.5 блока — скан срывается.

**Первый успешный скан железной руды** (`iron_ore` / `deepslate_iron_ore`) — один раз на игрока:

- Голос `blueprint_update.ogg` + title/чат (RU/EN): ассистент обновила данные; **два чертежа** — лабораторный стол и новый КПК; перенос — на столе, старый и новый КПК вместе.
- В КПК (вкладка **ЧЕРТЕЖ**) открываются чертежи **лабораторного стола** и **КПК МК-II**.
- Флаг пишется в данные мира (`LabBlueprintLogs`); повтор железа не повторяет beat.

Как проверить луч и unlock:

```
/give @s hostprotocol:scanner
```

Поставьте железную руду, удерживайте ПКМ на блоке ~2.5 с. Луч + полоса, затем чат unlock. Повтор на том же блоке — «уже просканировано». На мобе (корова / зомби) скан короче и повторяется. `/hostprotocol status` показывает `Lab blueprints` и число просканированных руд.

### Лабораторный стол и КПК МК-II

**Верстак 3×3** (3 золота сверху, 6 железа снизу):

```
Gold | Gold | Gold
Iron | Iron | Iron
Iron | Iron | Iron
→ hostprotocol:lab_table
```

Блок ставится. ПКМ открывает GUI **как верстак, но сетка 5×5 + выход** (не ванильные 3×3). Рецепт МК-II ищется сервером как 3×3 в любой подобласти 5×5; лишние предметы в сетке ломают крафт.

**На лабораторном столе (не на обычном верстаке):**

```
Iron | Glass | Iron
Iron | Redstone Dust | Iron
Iron | Glass | Iron
→ hostprotocol:pda_mk2  («КПК Host Protocol МК-II»)
```

Новый КПК: оболочка офлайн, пока на **лабораторном столе 5×5** не лежат вместе старый `hostprotocol:pda` и `hostprotocol:pda_mk2`. Результат — **активированный чистый MK-II** (NBT `Activated`). Голос `transfer_complete.ogg` + частицы. После переноса открываются чертежи **сыворотки** и **защитного костюма**.

Первое использование активированного MK-II: `module_online.ogg`, кольцо частиц, оверлей. Вкладки **ЗДОРОВЬЕ** (HP / голод / инфекция), **СКАНЫ**, **ИИ** (чистый ассистент). Неактивированная оболочка показывает вкладку **МОДУЛЬ** и сенсорный лог.

Проверка крафта без скана железа (читерски): `/give @s hostprotocol:lab_table` и ингредиенты, либо `/hostprotocol forceironscan`, либо сначала просканируйте железо, чтобы чертежи появились в КПК.

Перенос без крафта:

```
/hostprotocol forcetransfer
```

### Заражённые мобы, сыворотка, костюм

У очага живые сущности получают тёмный «энд-портальный» тинт и эффект инфекции. С убитых падает `hostprotocol:infected_flesh`. Сыворотка 3×3 (плоть + бутылка + золотой самородок) снимает эффект. Защитный костюм — полный сет (шлем/грудь/ноги/ботинки) из плоти + железа.

### День 5 — присутствие Septic

`dayIndex >= 5` (`/time set 96000`): рядом спавнится сущность **Septic**. На голове — фотореалистичное **лицо без глаз** (чёрная жидкость). Взгляд на тело/голову (широкий конус, до 64 блоков) сразу закрывает экран тем же лицом. Голоса нет. Чат один раз за взгляд (30 с).

```
/hostprotocol spawnseptic
```

`/hostprotocol status` показывает infection, focus, coords, septic, protocol breached, lab blueprints, transfer, MK-II boot.

Вне скоупа: полный ИИ босса Septic, концовка Энда, машина лечения мира.

### Протокол взломан (coords + connection)

Когда **оба** события случились, мир ставит `protocolBreached`. Клиент пишет флаг в папку игры: `.minecraft/hostprotocol/client.flags`.

**Главное меню после взлома:** панорама/фон испорчены глитчем; кнопка **Выход** не закрывает игру. Выйти можно закрытием процесса (мета-эффект PR #5).

**Повторный вход после взлома** (один раз на игрока): женский `system_error` + тихая сирена под VO, вкладка **СБОЙ**.

### День 3 — принудительный разрыв, если остаётесь

Если игрок **всё ещё в мире**, когда наступает день 3 (`/time set 48000` или `/time add 24000` с дня 2):

1. Сразу предупреждение в чат.
2. Через **10 секунд gameTime**: резкие помехи, женские `signal_lost` / `system_error_short`, длинный гудок `signal_lost_tone`.
3. Файл на рабочем столе `что_ты_такое.txt` (сигнал потерян / «что ты такое» / SESSION TERMINATED).
4. **Kick** на экран title (жёсткий disconnect из мира).

Один раз на игрока. Если ушли **до** kick — повторный вход **не** наказывает (отдельный breach-path title screen остаётся).

### Как прогнать день 2 → handshake → день 3

Нужны читы. После интро:

**Вариант A (одна команда):**

```
/hostprotocol day2
```

Смотрите чат: очаг → координаты → Septic.

**Вариант B (как игрок):**

```
/time add 24000
```

Очаг сразу. Подождите ~20–30 с — координаты. Ещё ~5–10 с — Septic без сна. Либо лечь в кровать в день 2.

**День 3 kick:**

```
/time set 48000
```

Не выходите 10 секунд: FX + гудок + kick + файл на рабочем столе.

`/hostprotocol status` показывает infection, focus, coords, septic, protocol breached, lab blueprints.
