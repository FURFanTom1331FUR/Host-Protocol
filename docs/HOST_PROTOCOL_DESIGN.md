# Host Protocol — дизайн-документ

**Статус:** черновик планирования (v0.1)  
**Платформа:** Minecraft **Fabric 1.20.1**  
**Жанр:** психологический / мета-хоррор  
**Ориентир:** сильнее The Broken Script (не копия)  
**Автор концепции:** Артём Скопенков  
**Документ собран:** 2026-09-17

---

## 1. Питч (одной фразой)

Мир сам является Ошибкой. Испытуемый (антивирус) должен за **100 дней** изучить заражение, построить лечение и очистить мир, пока **Host Protocol** и его лицо **Septic** ломают игру и игрока.

---

## 2. Названия

| Роль | Имя |
|------|-----|
| Мод | **Host Protocol** |
| Система / вирус | Host Protocol (заражение мира) |
| Антагонист (лицо) | **Septic** |
| Игрок | **Испытуемый** + рандомный код (пример: `С231А`) |

Стиль нейминга: «заражение» — система как болезнь мира, сущность как симптом.

---

## 3. Лор

### 3.1. Что такое «ошибка мира»

- Мир обнаружен **случайно** (пасхалка в духе Backrooms, но **по-своему**, не копия).
- **Мир и есть Ошибка** — не отдельный босс «внутри» мира.
- Мир постепенно заражается: блоки, структуры, мобы, вода, биомы.
- При загрузке мира текст вроде: **«Ошибка подключения к системе»** вместо обычной загрузки.

### 3.2. Кто игрок

- После заставки → «нажмите, чтобы продолжить» → титры **голосом и текстом**:
  - ты Испытуемый с рандомным номером;
  - ты в мире Host Protocol;
  - задача: исследовать мир, найти ошибку и устранить её.
- Игрок = **система-антивирус**: изучает и искореняет вирус.
- Вирус всячески мешает.

### 3.3. Кто Septic

- Septic **не сама Ошибка**.
- Мир (Ошибка) пытается устранить испытуемого и **создаёт** Septic как иммунный ответ / охотника.
- Связка: система заразила/является миром; Septic — видимое лицо, которое мешает.

---

## 4. Уникальность vs Broken Script

Обязательные отличия:

1. **Сюжет и концовки** (не только атмосфера).
2. **Игрок может дать отпор** (сыворотка, аппарат, машина лечения).
3. **Мультиплеер-страх** / фейковые тиммейты.
4. Прогрессия как у **Subnautica** (чертежи → станции → крафт из заражения).
5. Чёткий дедлайн миссии: **100 дней**.

Мета-фичи (все, но с эскалацией по дням):

- ломает чат / фейковые сообщения;
- подмена UI / ложные кнопки;
- глитчи экрана / искажения;
- угрозы сейву / «удаление» мира;
- знает имя / копирует игрока;
- фейковый мультиплеер;
- выкидывания, краши/ошибки, тестовые файлы — давление на нервы.

---

## 5. Прогрессия (Subnautica-like)

Порядок:

1. **Чертежи из структур** — находишь в мире.
2. **Цепочка станций:** сканер → лаборатория → машина лечения мира.
3. **Сыворотка из заражённых материалов** — чтобы самому не застрять в заражении.

Исследование кормит прогресс: без вылазок нет чертежей → нет аппарата → Septic и очаг побеждают.

## 6. Заражение мира (блоки и зоны)

### 6.1. Старт

- Новый мир на входе **тих** (кроме интро).
- **День 1:** почти ничего; появляется **туман**; у спавна **книга**, объясняющая ситуацию.
- **День 2 (рассвет):** книга/КПК фиксирует, что аномалия замечена; **очаг стартует сразу**, как только `dayIndex` становится 2 (не только ночью). Координаты — через ~20–30 с `gameTime`.
- **День 2 (ночь):** дополнительный catch-up, если очаг почему-то не вооружился. Auto-Septic ~5–10 с после координат; сон дня 2 — запасной триггер, ночь не пропускается на первую попытку.
- **День 3:** если игрок остаётся в мире ~10 с — помехи, женский VO, гудок, kick на title + файл на рабочем столе.

### 6.2. Очаг

- Одна стартовая точка (смещение от спавна мира, seed-детерминировано). Координаты **персистентны**.
- Место очага **всегда прогружено** (forced chunks).
- Рост: **медленный радиус** (камень, булыжник, земля, трава, дуб — стартовый набор).
- Заражает: блоки → (позже) биомы → **воду**. В этом срезе только блоки.

### 6.3. Блоки

- Не «каша», а **заражённые варианты** обычных блоков  
  (камень → заражённый камень, булыжник → заражённый булыжник и т.д.).
- **Заражённые блоки нельзя сломать.**
- Лечение **снимает** заражение: блок снова становится нормальным (не уничтожается).

### 6.4. Биом

- В заражённом биоме — не обычная слепота, а **заражённая слепота** (свой визуал).
- По мере заражения мир становится мрачнее и «непонятнее».

### 6.5. Измерения

- **Энд** — самое заражённое место.
- **Ад:** сначала без заражения. Вирус **проникает с игроком**. В Аду тик заражения быстрее: примерно **раз в 20 минут** (в обычном мире медленнее).
- Спасение Энда — **отдельная история** (концовка 2 / продолжение).

## 7. Заражённые мобы

Обычные мобы переписываются очагом (+ редкие особые, не зоопарк боссов каждый день).

### Получение вируса

- На заражённой территории / блоках.
- Не мгновенно: сначала эффект **«Инфицирование»**, затем стадии.

### Стадия 1 (~10 минут)

- Уже помечены; на них нападают обычные мобы.
- Сами слабые.
- При смерти — **облако заражения**; кто вошёл — тоже стадия 1.

### Стадия 2

- Полноценно заражены, сразу агрессивны.
- Сильнее, бегают быстро.
- Могут **ломать блоки**.
- Чуют цель в радиусе **~20 блоков** (не 200).

---

## 8. Заражение игрока

Тот же пайплайн: Инфицирование → Стадия 1 (~10 мин) → Стадия 2.

Источники: заражённые блоки, облака, удары заражённых.

### Стадия 1

- Лёгкий дрейф экрана/звука.
- Жёстче голод/усталость.
- Серые подсказки Host Protocol в чате.
- Сыворотка **лечит полностью**.

### Стадия 2

- Сильный глитч зрения.
- Septic сильнее чувствует / чаще вмешивается.
- Дебаффы к бою и крафту.
- Риск срыва мета (ложные UI / сообщения).
- Лечится **тяжело** (сильная сыворотка / лаборатория).
- **Не** game over и **не** превращение.

---

## 9. Карта дней (утверждённая игроком)

| Время | События |
|-------|---------|
| Вход | Заставка → «нажмите» → титры Испытуемый+код → «Ошибка подключения к системе». Мир тих. |
| День 1 | Туман. Книга у спавна. Заражения ещё нет. |
| День 2 | Рассвет: лог «заражение замечено», координаты ждут. Ночь (`37000`): старт очага. Через ¼ дня — координаты в КПК. Первый сон — срыв связи Septic, ночь не скипается. Заражённые блоки не ломаются. |
| День 5 | Появляется **Septic**, постепенно мешает. Мир мрачнеет. |
| Далее | Эскалация мета + рост очага. Постоянное давление (ошибки, выкиды, тестовые файлы). |
| Дедлайн | **100 дней** на уничтожение вируса. |

## 10. Концовки

### 10.1. Поражение (не успел за 100 дней)

- Игрок **выбит из тела**.
- Заходит и видит **своё заражённое тело**, как оно ходит.
- Режим **только spectator**; сменить гейммод нельзя.
- Весь мир заражён — игрок лишь свидетель провала.

### 10.2. Победа 1 — мир спасён

- Заражение уходит.
- Мобы **постепенно** восстанавливаются (не мгновенно).
- С убитых заражённых **больше не падает** эффект/облако заражения — цепочка чумы сломана.

### 10.3. Победа 2 — спасение Энда

- Отдельная история / продолжение. Не обязательна для v1.
